# Producten Beheer App

## Beschrijving
Dit is een softwareproduct bestaande uit twee onderdelen: een **Python API** en een **eenvoudige applicatie**.
De API regelt alle logica rondom producten in een digitale winkel. De applicatie gebruikt deze API om producten op te halen en weer te geven.

Met dit product laat ik zien dat ik begrijp hoe een backend en frontend samenwerken en hoe data via een API wordt verwerkt en weergegeven.

---

## Functies
- Producten toevoegen met naam en prijs.
- Overzicht van alle producten opvragen.
- Producten verwijderen.
- Alle data wordt via JSON verwerkt, zodat andere applicaties dit eenvoudig kunnen gebruiken.

---

## Technische details
- **Backend:** Python met Flask en Flask-cors
- **Frontend:** Eenvoudige HTML/JS applicatie
- **Data formaat:** JSON
- **API endpoint voorbeeld:** `http://127.0.0.1:8000/products`

---

## installatie
1. Zorg dat je pyhton 3.10 of hoger hebt en Flask en flask-cors hebt geïnstalleerd
2. Clone mijn repository
3. start eerst de app.py door 'python app.py' in je terminal te schrijven
4. daarna kun je een live html server activeren met index.html
5. Veel plezier!
